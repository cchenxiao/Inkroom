# M0.1a 作品方向规划 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 在当前开发分支顺序完成；用户已授权直接开发。

**Goal:** 一句立意生成 2–3 个方向，作者编辑选定，刷新及重启后保留。
**Architecture:** 独立 Intake/Direction 版本，异步模型任务固定输入快照。复用模型端口、结构化解析和调用预算，PostgreSQL 事务负责过期校验；前端 React Query 轮询任务。
**Tech Stack:** Go / pgx / JSON Schema / React / TanStack Query。
**Spec:** docs/backend-build-plan.md M0.1、docs/agent-orchestration.md §16.6。

## Global Constraints
- 不改章节 API、MSW 乐观锁或正式章节开工条件；M0 产物暂不进入正文/Bible/检索库。
- 类型不默认悬疑；参考作品只存作品名与参考维度，联网后续实现。
- 类型模板本阶段仅版本化数据配置，无插件框架、质量自动门禁。
- 按用户偏好只补关键风险测试，保留现有当前分支供本地页面直接查看。

## Review Focus
- 输入变更与迟到生成：旧结果可读但不能采用。
- 两窗口选定：预期方向版本不符时 409，不覆盖人工决定。
- 刷新/服务重启：任务不重复付费，未完成任务标中断。
- 空白/超长/未知字段：请求拒绝，模型输出必须过 Schema 和内容校验。
- 未启动后端：明确错误与重试，不能悄悄降级为 Mock。
